# 连续竖井规则 v3（2026-10-06 已定）

用户要求地图连续、随机障碍、回合切换不重置 Actor；镜头快于单位，完全画外时仅重布纵向，屏幕X不变；镜头停稳后角色从边缘走入画面。本节覆盖下方v2区段重置条款。

- 地图和单位使用累计纵向坐标，摄像机只向下推进。障碍按13行段提前生成，已生成障碍不在回合边界删除、重抽或挪动；当前原型仍为三波，不承诺无限世界。
- 清场时摄像机以650 milli-grid/tick前进26000（40tick）；友军沿原X向下行进，最多200/tick，受障碍阻挡则等待镜头越过。镜头快于单位，保证单位可完全离开上方画面。
- 摄像机到达终点且友军完全位于画外后，友军重布到新视口上方1200；重布前后均不可见，X、HP/阵亡/冷却/朝向/协议不重置。画面外安全带无障碍；镜头移动期间友军禁止提前入场。
- 镜头停稳后，友军以200/tick从上边缘走入，X不变；存活友军抵达入场位置后开始本波交战和危险计时。首波友军也从画外进入。
- 用户进一步明确：敌人提前布置，可在镜头到达前自行找掩体，由镜头带入画面。因此开局预生成三波6/7/8敌人及其Actor；未来波次敌人持续寻掩体，不参与当前波次伤害和胜负。敌人位置、HP、ID在波次边界完全保留，不复活、瞬移或重新生成。
- 地图预生成三波与中间连接区域，共65行；正常回合切换不销毁、重建或重新生成任何单位Actor。显式重开/切队伍是新一局；调试重建仅是隔离测试，不用于回合切换。
- 原即时激光、转速、路径、危险、三选一与50ms保持。v3独立Golden，不覆盖v1/v2历史样本；验收增加累计地图、画外重布前后可见性、X不变、入场时序与PIE Actor身份保持。

## 历史 v2（空间生命周期条款由v3覆盖）

用户授权完成障碍、自动避障/避险/射击位置、下行波次，并明确即时激光及转向速度上限。以下为本轮实验参数，覆盖下方 v1 单场规则；不宣称最终产品数值。

- 9×13 逻辑格，1000 milli-grid/格；横向位置参与规则。障碍占整格，同时挡移动和射线，不可破坏；单位不互相阻挡。每区段以 XorShift32 生成障碍，保留中央通路及出生区，并拒绝使自由区域不连通的障碍。
- 默认 seed=1；重开保留 seed，N/NEW SEED 换种子。3 个区段分别 6/7/8 个敌人。清场下行 40 tick，然后生成下一段；友军 HP、存活、冷却与已选效果保留，不补员、不回血；第三段清场胜利。全灭失败，同时全灭平局；总时限 6000 tick。
- 实验友军 HP600、伤害30、攻击间隔12 tick；敌方 HP90、伤害8、间隔32 tick。双方速度200 milli-grid/tick，射程3500；50ms/tick。
- 瞄准角以整数毫度存储，0°向右、90°向下，每 tick 最多转9000毫度（180°/秒），误差≤3000毫度才允许开火。跨0°走最短方向，正好180°固定正向。激光脉冲当 tick 命中，无在途弹丸；表现完整射线闪烁，无飞行光点。副射线也须满足射程、遮挡、瞄准锥；爆裂半径1500，不能穿障碍传播。
- 目标存活时保持目标；死亡后按二维距离、ID选敌。固定邻接顺序 BFS 搜索最近可达、无危险且在射程内/无遮挡的射击格；沿格中心路径移动，转向同步进行。射击格避开队友当前位置/路径下一格，较大ID单位在聚集时主动分散；这是站位选择，不引入单位物理碰撞。无可射击位置则等候，不穿墙或瞬移。危险内优先搜索安全格；安全位置避免走进已预警危险。
- 每区段第60 tick起每120 tick，向最小存活友军ID所在位置发出半径1200的范围攻击预警，24 tick后对范围内双方造成60伤害；按模拟时钟结算，单位自动撤离。此为环境危险，不是可闪避的激光弹丸。
- tick100开放一次三选一，跨区段保留：增伤50%/瞄准锥内额外一目标50%伤害/主目标周边爆裂50%伤害。
- 每步固定顺序：命令、预警生成、选敌、基于同一旧状态规划移动、同时移动与限速转向、生成即时射击、汇总激光和到期危险伤害、死亡、清场/下行/最终结算。已生成攻击不因同 tick 死亡取消。
- 单视口展示下行过渡及深度；全部逻辑 C++、蓝图仅资产。结果导出 seed/RNG、区段、下行、避险等计数及事件 hash；v1 Golden 保留历史，v2单独验收。
- 本轮及后续可通过 Editor/Live Coding + Terminal/MCP 完成验收和演示，不要求每轮重新打包；旧 Windows 包仍为 v1，不能当作 v2 交付。

## 历史 v1（已被上述条款覆盖）

来源：用户批准的玩法优先计划及可打包蓝图原型请求。仅用于本轮实验。

- 默认 2 友军对 6 敌人，允许 5 对 6。友军位置 0，敌军 4000 milli-grid；横向编队仅表现。
- 友军 HP300、伤害20、间隔20 tick；敌人 HP100、伤害10、间隔30 tick。射程1000，移动25/tick；50ms/tick。
- 保持存活目标，死亡后重选最近敌人，同距选小 ID。接近/交战/死亡三态。
- 每步：处理选择命令、选敌、同时移动、生成攻击、汇总伤害、死亡、胜负、输出。首次进入射程可攻击；同 tick 互杀不取消已生成攻击。
- tick100 出现三选一，不暂停且不自动选：全队增伤50%；增加一名射程内次目标（50%伤害）；或主目标周围500内其他敌人受到50%爆裂伤害。比例向下取整。
- 选择只生效一次；无效/重复/结束后命令不修改状态。下一模拟步生效。目标排序按距离后 ID。
- 一方全灭结束，同时全灭平局；1200tick 超时平局。即时伤害，视觉不反向结算。
- 720×1280 单视口；重开/2或5人/暂停/单步/1、2、5、10倍速。鼠标按钮及快捷键均可操作。
- 无随机行为，seed 为保留元数据；没有能量、热量、技能、养成、存档。
- 配置以 C++ fixture 为唯一数值来源；Blueprint 仅资产管理、表现参数及实例化，所有逻辑和调度由 C++ 实现。
